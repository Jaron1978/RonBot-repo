# RON-04 — Production RonBot Character

**Status:** Complete

## Objective

Turn the approved Robot Ron concept into the canonical production character used by the RonBot website experience.

## Approved visual direction

The established RonBot concept combines:

- Robot Ron character design.
- AWS hoodie.
- Redpanda T-shirt visible beneath the hoodie.
- Azure beanie.
- Google-themed khaki trousers.
- Study books/material carried under his arm.

The combination represents Ron's cloud and AI learning/project direction while keeping Redpanda prominent in the character design.

## Production asset requirements

The production character should include:

- A high-resolution master asset.
- A transparent-background website version.
- Web-optimised output suitable for the RonBot frontend.
- Consistent proportions and visual identity.
- A canonical neutral/default pose.

Animation and interaction states such as the floating launcher, thinking feedback and reduced-motion support were implemented separately during RON-06, preserving RON-04 as the character-design milestone.
